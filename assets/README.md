# AssistIA/assets/

Dossier assets/ du projet AssistIA  
Contient l’ensemble des ressources statiques nécessaires aux modules, interfaces et opérations IA.

### Contenu
```text
- Images opérationnelles (PNG, JPG, SVG)
- Icônes tactiques
- Logos AssistIA
- Polices et éléments UI
- Médias divers (schémas, bannières, visuels techniques)
```

### Objectif
Centraliser toutes les ressources statiques afin de :
```text
- Garantir une structure claire et disciplinée
- Éviter la duplication de fichiers
- Faciliter la maintenance et l’évolution des modules AssistIA
```

### Structure
```text
assets/
├── icons/          # Icônes tactiques pour l’UI
├── logos/          # Logos AssistIA, variantes, versions
├── ui/             # Éléments d’interface (polices, cadres, visuels)
├── banners/        # Bannières, headers, visuels de présentation
└── diagrams/       # Schémas techniques, architecture, workflows
```

### Bonnes pratiques
```text
- Nommer les fichiers de manière explicite et normalisée  
- Optimiser les images avant intégration  
- Utiliser des sous‑dossiers pour chaque catégorie de ressources  
- Ne jamais stocker de fichiers temporaires ou non utilisés
```

### Notes AssistIA
Ce dossier est utilisé par les modules :
```text
- Core/ (UI, prompts, interfaces)
- Ops/ (schémas tactiques)
- Docs/ (bannières, visuels techniques)
```

   - Maintenir une cohérence stricte entre les ressources et les modules est essentiel pour la stabilité du projet.
